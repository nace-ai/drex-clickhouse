## Integration branding

The README uses Nace artwork and a plain-text compatibility reference to ClickHouse®.
The [ClickHouse trademark policy](https://clickhouse.com/legal/trademark-policy) permits the
“Drex for ClickHouse” naming form subject to its conditions: any distributed ClickHouse binaries
must be unmodified, compatibility with the then-current APIs must be maintained, and the required
attribution must accompany product descriptions. This wording is not a certification of compatibility.

The policy permits word marks, but not the logo, for compatibility statements without a separate
logo license. Do not restore a combined Nace/ClickHouse logo header based only on downloadable artwork.
